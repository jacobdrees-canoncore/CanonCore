# The code is AGPL-3.0

The code is AGPL-3.0, so anyone who runs a modified CanonCore for other people must publish their changes. Nobody can turn it into a closed hosted service. Provider data is used under each Provider's own terms, most of them non-commercial, which the README states and the app shows as attribution (Settings › About, plus TMDB's logo and notice).

## Considered Options

- MIT: rejected, because it would allow a closed, hosted fork.
- GPL-3.0 (Audiobookshelf, Navidrome) or GPL-2.0 (Jellyfin): rejected, because their copyleft does not reach a server that is only run over a network, not distributed. Immich uses AGPL-3.0 (licences verified with the GitHub API, 2026-09-28).

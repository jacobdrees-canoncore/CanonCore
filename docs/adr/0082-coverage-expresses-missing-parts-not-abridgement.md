# Coverage expresses missing parts, never abridgement

An abridged reading covers the whole extent at reduced fidelity. Modelled as coverage intervals it
either claims full coverage, which is false, or invents boundaries, which are fabricated.

So abridgement is a `category` statement on the edition, and edition coverage stays what it is: a
set of intervals saying which parts of the work an edition actually contains.

This came out of the Harry Potter pass on 2026-09-05, where the abridged readings are the case that
breaks a naive reading of ADR-0060.

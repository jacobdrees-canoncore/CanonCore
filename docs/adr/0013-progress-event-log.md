# Progress is an append-only event log per Profile and Edition

Players report about every 10 seconds into an append-only log kept per Profile and per Edition, and position and "watched" are derived from it, so history is never lost and Progress made offline on several devices merges by time, as in old ADR-0019 (canoncore-history). Versions of one Edition share Progress while a different Edition has its own, as in Plex, and each event carries a position suited to its medium (for video and audio, the proportion of the played Version's measured runtime, from 0 to 1, which a player reports in seconds of its Version and the server divides; an EPUB CFI or Readium locator, which survives a font-size change; a comic page) and a source field, so history imported from a Provider fits the same log.

## Consequences

- Versions of one Edition can differ in runtime (film-originated material runs about 4% fast in PAL), so a PAL and an NTSC copy are Versions of one Edition with one watched state, and Progress is stored as a proportion of each Version's measured runtime, never as seconds or with a fixed speed-up, so switching Versions lands on the same scene. None of the products reviewed does this, verified 2026-10-02: Plex shares one offset in milliseconds (`viewOffset`) across the versions of an item, Jellyfin since 12.0 keeps a resume point per version and shares only the played state (PR #17044, `VersionResumeData.cs`), and Kodi resumes per file.
- A Profile's year in review is built from this log: time watched, listened and read; its most-played Items, Shows and Artists; the Orderings it finished; its longest streak and its busiest day (the Owner, 2 Oct 2026). Letterboxd builds its personal year in review from dated diary logs and Spotify Wrapped from a year's streams (both verified 2026-10-02); Plex's Rewind is platform-wide, not per user.
- "Finished" is defined per medium: for video and audio, time remaining (about the last 2 minutes), not a percentage, as in old ADR-0085 (canoncore-history); for a book or comic, reaching its last chapter or page.

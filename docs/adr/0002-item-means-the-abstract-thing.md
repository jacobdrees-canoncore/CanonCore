# `Item` means the abstract thing, not the file

IFLA LRM and BIBFRAME both use *Item* for the physical or digital copy. We use it for the
abstract thing being catalogued, which is the opposite.

Taken deliberately: *Item* is the word this product's users reach for, and internally the model
is unambiguous. The cost is external only, and lands on anyone comparing our model to the
standards it derives from.

# A standard read protocol is refused

OPDS, Subsonic and every other candidate IS TYPED BY MEDIUM, so shipping one reintroduces sideways
the medium-typing this model refuses at the group level.

Both incumbents publish their own documented API instead — Jellyfin ships an OpenAPI contract at
api.jellyfin.org — rather than adopting a medium-typed protocol.

THIS DOES NOT REACH OUTBOUND PUSH. Scrobbling to Trakt or anywhere else is DEFERRED, by name, rather
than refused: it is not interchange between instances and nothing here has ever argued against it.
Naming it stops the refusal being read wider than it is, which is how it was being read. Stated explicitly because the evidence FOR a read protocol is recorded next to it,
and silence there reads as an unmade decision rather than a made one.

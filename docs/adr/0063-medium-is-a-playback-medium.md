# Medium is a playback medium, closed at four values

`medium` is video, audio, text or image: how an edition is consumed by a renderer this product
actually has. It is not a taxonomy of works.

A stage production and a video game are neither, and both are still complete catalogue entries — a
`work` item with a category statement and zero editions. Do not add `performance` or `game`, or
medium is back at seventy values within a year.

The closure is what makes the completion rules tractable, and it is why those rules can afford to
branch somewhere other than this enum. Where they branch, and why, is
[[0085-completion-branches-on-the-locator]]'s — cited rather than restated, because an earlier
version of this paragraph stated it as a decision taken here.

## Supersedes

An earlier rule held that a kind exists only if a renderer for it is committed. It is reversed here:
CATALOGUING AND DISPLAYING ARE SEPARABLE. A renderer is needed only when a file is attached and
someone presses play; a novel with no reader is a complete entry.

The earlier rule would have made ADR-0003 impossible — an unproduced work, a person, a place and a
concept all have complete catalogue entries and nothing to render. It is also what keeps this
record's four values closed: a stage production and a video game are neither, and both are still
complete entries.

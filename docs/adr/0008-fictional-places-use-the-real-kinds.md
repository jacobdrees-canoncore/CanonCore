# Fictional places and organisations use the real kinds

They go in `place` and `organisation` carrying `fictional: true` as a statement, rather than
getting kinds of their own.

The standards' exclusions are scoped to a bibliographic universe and ours is fiction. Keeping the
kind shared means conformant data can still be exported. A thing that is both an institution and
a building is two items, related — the standards genuinely separate them.
